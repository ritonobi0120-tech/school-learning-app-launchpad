面積の塔を学校のGASへ

学校アカウントで、このページを見ながら進めます。「コピー」を押して、GASに貼るだけ。

A　1つ貼るだけ（まずこっち）

開くたびに共有版の面積の塔を取ってきて見せます。こちらで直すと、子どもの画面にもそのまま出ます（貼り直しなし）。

// 面積の塔（学校用）: 開くたびに共有版を取ってきて見せる。子どものデータはどこにも送らない
function doGet() {
  var url = 'https://ritonobi0120-tech.github.io/school-learning-app-launchpad/menseki-tower/?t=' + Date.now();
  var html = UrlFetchApp.fetch(url).getContentText('UTF-8');
  return HtmlService.createHtmlOutput(html)
    .setTitle('面積の塔')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}
  1. 学校アカウントで script.google.com を開き、左上の「新しいプロジェクト」
  2. 左上の「無題のプロジェクト」を押して、名前を「面積の塔」に
  3. 「コード.gs」の中を全部消して（Ctrl+A → Delete）、上のコードを貼る（Ctrl+V）→ Ctrl+S で保存
  4. 右上の「デプロイ」→「新しいデプロイ」
  5. 「種類の選択」の歯車 →「ウェブアプリ」
  6. 「次のユーザーとして実行」は「自分」、「アクセスできるユーザー」は学校のドメイン内の全員（e-net.nara.jp）→「デプロイ」
  7. 「アクセスを承認」が出たら押して、自分の学校アカウントを選び「許可」（外のページを読みにいくための許可）
  8. 出てきた「ウェブアプリ」のURLを「コピー」→ 新しいタブで開き、塔の画面が出たらできあがり。このURLをClassroomへ

「許可」のところで止められた・開いたらエラーが出た、のときは B へ。

B　6つ貼る（A で止まったとき）

外のページを読みにいかないので、許可の画面は出ません。直したときは Core と Ui を貼り直します。

Codeもとからある「コード.gs」に貼る・1KB
Index新しいHTML「Index」に貼る・1KB
Styles新しいHTML「Styles」に貼る・73KB
Core新しいHTML「Core」に貼る・343KB
Assets新しいHTML「Assets」に貼る・272KB
Ui新しいHTML「Ui」に貼る・356KB

  1. A の 1〜2 と同じ
  2. 「コード.gs」の中を全部消して、上の「Code」を貼る
  3. 左の「ファイル」の横の「＋」→「HTML」→ 名前に Index と入れて Enter → 中を全部消して「Index」を貼る
  4. 同じように Styles・Core・Assets・Ui も作って貼る（名前は大文字・小文字もこのまま）。Core と Ui は大きいので、貼ったあと数秒待つ
  5. Ctrl+S で保存 → A の 4〜6 と 8 と同じ
